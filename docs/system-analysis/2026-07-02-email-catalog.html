How the system works:
  • Every client email subject is automatically prefixed with the client's code: {{code}} - …
  • Clients marked closed ("done") never receive automated emails.
  • Each department has a master switch in Settings → Email automations (Sales / Accounting / Technical — all currently ON), plus a per-email switch.
  • Placeholders like {{name}}, {{amount_gross}} are filled in automatically per recipient.
